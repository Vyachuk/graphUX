# 0001. Стек: Vite + React + TypeScript + React Flow

**Статус:** Accepted

## Контекст
Потрібен нескінченний канвас, на якому сутності (таблиця людей, людина, ресторан…) відкриваються як окремі ноди, з'єднані стрілками, і по яких можна переходити кліками.

## Рішення
- **React Flow (`@xyflow/react` v12)** — канвас: pan/zoom, кастомні ноди з довільним React-вмістом, ребра, `fitView` з анімацією.
- **Vite** — dev-сервер і збірка, без конфігураційного шуму.
- **TypeScript** — типи сутностей (`EntityRef`) гарантують, що кожен клік веде на існуючий тип.
- Без state-менеджера: стан навігації маленький, живе в одному `useReducer`.

## Наслідки
- Весь UI сутностей — звичайні React-компоненти всередині нод.
- Клікабельні/скрольні елементи всередині нод повинні мати класи `nodrag` / `nowheel`, щоб не конфліктувати з pan/zoom.
- React Flow ставить `pointer-events: none` нодам, які не draggable і не selectable. Тому кожна нода отримує `style: { pointerEvents: 'all' }`, інакше кліки всередині не працюють.
