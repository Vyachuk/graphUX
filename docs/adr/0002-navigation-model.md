# 0002. Модель навігації: стек сутностей + фокус

**Статус:** Superseded by [0009](0009-branching-tree.md)

## Контекст
Користувач клікає на сутність у ноді — справа відкривається нова нода. Може повернутись до попередньої ноди й клікнути щось інше — тоді «гілка» справа має замінитись, як у браузерній історії.

## Рішення
Стан — це лінійний стек і індекс фокуса:

```ts
type EntityRef = { type: EntityType; id: string };
type NavItem   = { ref: EntityRef; via?: string }; // via — підпис ребра ("loves", "lives in")
type NavState  = { stack: NavItem[]; focus: number };
```

Дії (reducer):
- `open(fromIndex, ref, via)` — обрізати стек після `fromIndex`, додати `ref`, фокус на нову ноду.
  Якщо `stack[fromIndex + 1]` вже той самий `ref` — не обрізати, тільки перемістити фокус.
- `focus(index)` — лише змінити фокус (клік по згорнутій іконці, стрілки ←/→).
- `close(index)` — обрізати стек до `index - 1` (корінь закрити не можна).

Корінь стеку — завжди таблиця людей.

## Наслідки
- Нода «знає» лише свій `index`; навігація доступна через React Context (`useNav()`), тож компоненти сутностей не залежать від React Flow.
- Лінійний стек навмисно, не дерево: простіше правило згортання (ADR-0003) і лейаут (ADR-0004).
