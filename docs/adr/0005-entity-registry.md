# 0005. Реєстр із 5 сутностей і спільна обгортка ноди

**Статус:** Accepted

## Контекст
Потрібно 5 заготовок компонентів, і додавання нового типу має бути дешевим.

## Рішення
Один тип ноди React Flow — `entity` (`EntityNode`). Він відповідає за: хедер, кнопку закриття, згорнутий стан, хендли для ребер. Вміст рендериться з реєстру:

```ts
const registry: Record<EntityType, EntityDef> = {
  people:     { icon, label, width, title(id), Component },
  person:     { ... },
  restaurant: { ... },
  city:       { ... },
  dish:       { ... },
};
```

5 компонентів і їхні переходи:

| Компонент      | Клік веде на                         |
| -------------- | ------------------------------------ |
| `PeopleTable`  | рядок → Person                       |
| `PersonView`   | улюблений ресторан, місто, друзі     |
| `RestaurantView` | місто, страви, фанати (Person)     |
| `CityView`     | мешканці (Person), ресторани         |
| `DishView`     | ресторан, хто любить (Person)        |

Компоненти отримують `id` і викликають `useNav().open(ref, via)`; спільний елемент `<EntityLink>` рендерить клікабельне посилання з класом `nodrag`.

## Наслідки
- Новий тип = файл-компонент + рядок у реєстрі + тип у `EntityType`.
- Компоненти сутностей нічого не знають про канвас.
