# 0020. Коментарі через асистента: голосом і в чаті

**Статус:** Accepted · розширює [0010](0010-comments.md) (коментарі) і [0018](0018-ai-assistant.md)/[0019](0019-voice-robustness.md) (асистент, голос)

## Контекст
Потрібно залишати коментар до будь-якої сутності голосом (і в чаті). Голосом рідко кажуть усе одним реченням із двокрапкою: зазвичай «залиш коментар до Львова», пауза, потім сам текст — із паузами посеред думки.

## Рішення
- **Нові події асистента:** `comment { target, text, label }` — сесія записує коментар від імені поточного користувача (вибір «Ви»); `await { awaiting }` — асистент чекає продовження. `GraphContext.awaiting` передає моку, що наступна репліка — текст коментаря.
- **Одною фразою:** «залиш / напиши / додай / запиши / прокоментуй / коментар …»:
  - `до X: текст`, `до X — текст`, `… що текст`;
  - голосом без розділових знаків: «до Львова тут дуже затишно» — ціль береться як найкоротший початок із найкращим збігом назви, решта — текст;
  - без цілі — поточна картка (картка-відповідь асистента пропускається: коментуємо те, звідки питали); «до звіту Пʼяної вишні» — звіт; «до компанії» — остання відкрита компанія.
- **У два кроки:** без тексту асистент питає «Що написати в коментарі до «X»?», а наступна репліка (голосом без «Гей, граф» або в чаті) стає текстом; «скасуй» — без коментаря.
- **Диктування голосом:** пауза завершення довша (`DICTATION_SILENCE_MS = 2600` проти 1300), на текст чекаємо до `DICTATION_WAIT_MS = 15000`.
  - Нове «Гей, граф» — завжди нова команда: скасовує незавершене диктування, а пауза для неї звичайна.
  - Якщо розмова затихла й голос повернувся до очікування ключового слова, диктування скасовується (`onIdle`).
- **Інтерфейс:** підказка «✎ Коментар до «X» — скажи або напиши текст · скасувати», у полі вводу «Текст коментаря…»; підказки-фрази під час диктування сховано, бо клік на них став би текстом коментаря. «Залиш коментар» є серед підказок під людиною, рестораном і фінансами.
- **Скасувати** відповідь — видаляє записаний нею коментар. Якщо ціль відкрита, фокус переходить на неї, щоб було видно лічильник коментарів.
- Текст коментаря зберігає оригінальне написання (регістр, розділові знаки); ключове й вставні слова на початку прибираються (`stripLead`).

Попутно: пошук сутностей порівнює **усі можливі основи** слова, а не лише найкоротшу (інакше «Львова» → «львов» не збігалося з «Львів» → «льв»).

## Наслідки
- Тести: одна фраза з двокрапкою й без неї, ціль-звіт, коментар до поточної картки, картка-відповідь як фокус, два кроки, «скасуй» під час диктування, читання ≠ запис коментарів, фокус на відкриту ціль.
- Сценарій у Chrome з фейковим розпізнаванням: коментар у чаті й «Скасувати»; голосом «Гей граф, залиш коментар до Львова» → пауза 1,9 с посеред тексту не обрізає → коментар «Тут дуже затишно особливо взимку» на картці Львова; тиша скасовує диктування; нове «Гей граф, покажи …» — звичайна команда.
