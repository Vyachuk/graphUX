# 0006. Мок-дані як граф зв'язків

**Статус:** Accepted

## Контекст
Бекенду немає, але переходи мають бути змістовні й циклічні (людина → ресторан → фанат → місто → …).

## Рішення
Статичний модуль `src/data.ts` з масивами `people`, `restaurants`, `cities`, `dishes`, що посилаються одне на одного через `id`. Зворотні зв'язки (мешканці міста, фанати ресторану, хто любить страву) — обчислюються функціями-селекторами, а не дублюються.

## Наслідки
- Заміна на API пізніше — це заміна селекторів на запити (напр. React Query) без змін у навігації.
