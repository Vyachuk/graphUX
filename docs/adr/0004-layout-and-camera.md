# 0004. Горизонтальний автолейаут і камера

**Статус:** Accepted

## Контекст
Ноди змінюють розмір при згортанні/розгортанні. Позиції треба перераховувати, а камера має показувати активну ділянку.

## Рішення
- Ноди не перетягуються (`nodesDraggable={false}`); позиції повністю обчислюються зі стану.
- Лейаут — ліворуч-праворуч: `x` накопичується як сума ширин попередніх нод + `GAP`. Ширина розгорнутої ноди задається типом (таблиця ширша), згорнутої — `COLLAPSED = 72`.
- Усі ноди вирівняні по верху (`y = 0`). Хендли ребер зафіксовані на висоті `28px` — це центр хедера картки й центр кружка згорнутої іконки, тож ребра завжди прямі горизонтальні лінії незалежно від висоти нод.
- Зміна позицій анімується CSS-переходом `transform` на `.react-flow__node`.
- Після кожної зміни стану камера робить `fitView` лише по розгорнутих нодах (`maxZoom: 1`, `duration: 400`).
- Ребра — `smoothstep` між сусідніми нодами, з підписом `via`.

## Наслідки
- Нема ручного позиціювання — канвас завжди охайний.
- `fitView` викликається після вимірювання нод (через `requestAnimationFrame`), бо висота нод залежить від вмісту.
