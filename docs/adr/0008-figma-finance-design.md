# 0008. Дизайн із Figma: темна «скляна» тема і фінансові ноди

**Статус:** Accepted · змінює вигляд з [0004](0004-layout-and-camera.md), [0005](0005-entity-registry.md); розширює [0007](0007-extended-domain.md)

Джерело: Figma `GraphUX-Team`, фрейм `638:4192` (Financial Report); токени фону й іконок швидкого доступу з `47:1073` (Start page).

## Контекст
Команда намалювала цільовий вигляд графа на прикладі фінансових звітів ресторанів: темний фон, напівпрозорі картки, KPI-плитки, спарклайни, донат-діаграма, чипи періодів і зелені конектори між нодами.

## Рішення

### 1. Тема для всього застосунку
Замість світлої теми вводимо токени з макета:

| Токен              | Значення                                             |
| ------------------ | ---------------------------------------------------- |
| фон канвасу        | `linear-gradient(-60deg, #1e3740 17%, #001522 110%)` |
| картка             | `rgba(255,255,255,.07)`, border `rgba(255,255,255,.15)`, radius 8, padding 21 |
| вкладена картка    | `rgba(255,255,255,.03)`, border `rgba(255,255,255,.1)` |
| заголовок          | SF Pro Display Bold 14 / 20, `#fff`, tracking .35   |
| підзаголовок, мітки| 12 / 16, `rgba(255,255,255,.4)`                      |
| позитив / негатив  | `#34d399` / `#f87171`                                |
| акценти донату     | `#818cf8`, `#34d399`, `#f472b6`, `#fb923c`           |

Хедер кожної картки такий, як у макеті: заголовок і підзаголовок зліва, круглий бейдж 32px з іконкою праворуч. Згорнута нода — плитка 33px з підписом, як іконки швидкого доступу на Start page.

### 2. Конектори
Кастомне ребро `graph`: крива Безьє з півкруглим «язичком» (r = 7) біля джерела, як у макеті. Ребро, що веде до фокуса, зелене (`#34D399`), решта сірі (`#5B5F5D`). SVG-конектори з Figma намальовані під конкретні координати, тому відтворені в коді, а не вставлені картинками.

### 3. Три нові сутності
| Тип          | Вигляд (вузол Figma)                                           | Клік веде на          |
| ------------ | -------------------------------------------------------------- | --------------------- |
| `report`     | Financial Report ресторану: KPI Revenue/Expenses, 2 спарклайни, донат витрат (`638:2318`) | `metric`              |
| `metric`     | KPI-картка з зеленою рамкою + спарклайн + чипи періодів (`638:2474`, `638:2517…2523`) | `comparison`          |
| `comparison` | Два KPI поруч: обраний період і поточний квартал (`638:2528`)  | —                     |

`Restaurant` отримує посилання «Фінансовий звіт». Додаємо ресторани з макета (Реберня, П'яна вишня, ВСЛ). Цифри П'яної вишні збігаються з макетом.

Реєстр (ADR-0005) отримує необов'язкові поля: `subtitle(id)`, `iconSrc` (SVG з Figma замість емодзі) і `chrome: 'card' | 'bare'`. Для `bare` обгортка не малює хедер, бо `metric` і `comparison` у макеті без нього.

### 4. Графіки
Спарклайни й донат рендеряться з даних як SVG, бо це дані, а не статичні ассети. Статичні іконки з Figma (`ChartDonut`, trend up/down) лежать у `src/assets/figma/`.

## Свідоме відхилення від макета
У макеті деталі відкриваються **ліворуч-вниз** від звіту. Ми лишаємо **ліворуч-праворуч** (ADR-0002/0004 і початкова вимога «відкриється справа»): стек лінійний, і змішані напрямки в одному ланцюжку накладаються. Якщо команда вирішить дзеркалити весь граф, це один параметр у `buildGraph` (x накопичується з протилежним знаком).

## Наслідки
- Весь застосунок переходить на темну тему. Світлої більше немає.
- Нові фінансові ноди широкі (до 831px), тож `fitView` частіше зменшує масштаб, коли розгорнуто дві такі ноди.
