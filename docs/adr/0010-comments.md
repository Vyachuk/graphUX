# 0010. Коментарі та взаємодія на нодах

**Статус:** Accepted

## Контекст
Граф поки лише для перегляду. Команда хоче обговорювати дані прямо на канвасі: лишати коментарі до звіту, людини чи ресторану, бачити, де вже є обговорення, і реагувати на чужі коментарі.

## Рішення

### Модель
```ts
type Comment = {
  id: string;
  target: string;      // refKey сутності, напр. "report:r8"
  authorId: string;    // id людини з мок-даних
  text: string;
  createdAt: number;
  likes: string[];     // id людей, яким сподобалось
};
```
- Коментар прив'язаний до **сутності**, а не до ноди дерева: якщо одна сутність відкрита в кількох гілках, тред у них спільний.
- Чистий reducer `commentsReducer` з діями `add`, `remove`, `toggleLike`.
- **Поточний користувач** — одна з людей у мок-даних, обирається в панелі праворуч угорі. Від його імені пишуться коментарі й ставляться лайки. Видаляти можна лише власні коментарі.

### Збереження
`localStorage` (`graphux.comments.v1`) з `try/catch`: без бекенду це найпростіший спосіб пережити перезавантаження. Якщо сховище недоступне, застосунок працює без збереження. Під час першого запуску додаються кілька демо-коментарів. Коли з'явиться API, reducer лишиться, а зміниться лише шар збереження.

### UI
- У хедері кожної розгорнутої картки є кнопка **💬 N**, яка розкриває тред унизу картки. У нод без хедера (`bare`) кнопка плаває поруч із ×.
- **Тред**: автор (аватар з ініціалами), відносний час («5 хв тому»), текст, ❤️ з лічильником, видалення своїх коментарів. Поле вводу: Enter надсилає, Shift+Enter переносить рядок.
- **Ім'я автора клікабельне** і відкриває людину новою гілкою (ADR-0009). Так коментарі теж стають частиною навігації графом.
- **Згорнута іконка** показує бейдж із кількістю коментарів, тож обговорення видно навіть на згорнутих нодах.

### Взаємодія з канвасом
- Поле вводу позначене `nodrag nowheel nopan`. Навігація стрілками ігнорує події з полів вводу.
- Відкритий тред змінює висоту ноди, а лейаут з виміряних висот (ADR-0009) сам відсуває сусідні гілки.

## Наслідки
- Коментарі бачить лише той, хто їх написав: вони живуть у браузері користувача, спільного сховища поки немає.
- Новий провайдер `CommentsProvider` обгортає застосунок поруч із `NavProvider`.
